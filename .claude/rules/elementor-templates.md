# Template Elementor esportati

- Questi JSON sono **export** dei template Elementor (header, footer, loop, single, home), tenuti come backup e riferimento.
- La versione "vera" è nel database. Il JSON non si modifica a mano: si cambia il template nell'editor di Elementor e poi lo si riesporta qui (*Template → Esporta*).
- Gli URL dentro i JSON vengono dall'ambiente in cui sono stati esportati. Dopo un import vanno sostituiti con *Elementor → Strumenti → Sostituisci URL*.
